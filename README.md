# 🐾 BarkHaven — Pet & Dog Adoption Sanctuary

A modern, responsive web application for dog lovers and pet parents, featuring high-definition canine profiles, an interactive breed matchmaker quiz, adoption application workflow, canine wellness guides, smooth hover animations, and verified Google Maps reviews from **Fish & Pets Paradise** (Deep Nagar, Jalandhar).

---

## ✨ Features

- **🐕 Hero Showcase**:
  - Fluid first-load typewriter slogan effect with animated glowing cursor.
  - Featured Golden Retriever spotlight card with live adoption status.
  - Quick multi-criteria search bar (Breed, Size, Age stage).
  - Live trust stats (1,850+ Adoptions, 100% Vet-Checked, 99.4% Match Rate).

- **🔍 Interactive Dog Catalog**:
  - Category filters (*All Pups*, *High Energy & Sporty*, *Family Friendly*, *Apartment Friendly*, *Puppies*, *Gentle Seniors*).
  - Real-time instant keyword search and sorting (Featured, Youngest, Oldest, Name A-Z).
  - Visual activity & energy level meters.
  - Micro-animated heart button to save favorites with dynamic badge counter.

- **🎯 Breed Matchmaker Quiz**:
  - 3-step interactive questionnaire (Living Space, Daily Activity Level, Dog Parenting Experience).
  - Algorithmic scoring showing top compatibility matches with calculated percentage badges.

- **📝 Fast-Track Adoption Application Modal**:
  - Detailed medical clearances, ideal living environments, and rescue backstories.
  - Interactive multi-field application form with celebratory confetti on submission and unique reference code.

- **🩺 Canine Wellness & Care Hub**:
  - Tabbed guides for Nutrition & Diet, Positive Reinforcement Training, Core Vaccines, and the 3-3-3 Rule Checklist.

- **📍 Google Maps Verified Reviews (Fish & Pets Paradise)**:
  - Official Google Maps 4.6 ★★★★★ rating badge based on 337+ reviews.
  - Direct links to *"View on Google Maps"* and *"Get Directions"*.
  - Authentic customer reviews highlighting pure breed quality and veterinary guidance from Harman Basra.

- **🎨 Design & Aesthetics**:
  - Dark Mode & Warm Sand Light Mode with seamless theme toggling.
  - Professional light-sheen sweep and 3D depth zoom on image hover.
  - Pure Vanilla HTML5, CSS3, and JavaScript (Zero external framework dependencies).
  - Clean Lucide SVG icons.

## 🚀 How to Run Locally

### Option 1: Using PowerShell (Built-in Zero Dependencies)
1. Open PowerShell inside the project directory:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\server.ps1
   ```
2. Open your browser at:
   ```
   http://localhost:8080/
   ```

### Option 2: Using VS Code Live Server
1. Open the project folder in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Using Python
```bash
python -m http.server 8080
```
